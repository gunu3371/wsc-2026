# wsc-2026-2

각 과제 구현은 서로 독립된 과제 루트로 관리한다.

- 1과제: `task1/00002`, `task1/00003`, `task1/00007`
- 2과제: `task2` (과제번호 `00002`)
- 3과제: `task3`

2과제의 `00007`은 제외되었으며, 기존 `task2/00002`의 파일은 `task2/`로 이동했다. `task1/<과제번호>`, `task2`, `task3`는 디렉터리, `terraform.tfvars`, Terraform root module/state, 적용·채점·정리 절차를 공유하지 않는다. 각 과제의 `README.md`를 기준으로 해당 과제 루트에서 실행한다.
